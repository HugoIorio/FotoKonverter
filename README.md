# 🖼️ FotoKonverter

O **FotoKonverter** é um software de código aberto que permite redimensionar, comprimir e converter o formato de diversas imagens rapidamente. Útil para quem valoriza a privacidade e a possibilidade de executar programas de forma 100% local.

Fiz este projeto como forma de ter contato com a linguagem Python e criação de interfaces gráficas. O resultado é completamente funcional, embora eu acredite que ainda há vários pontos de melhoria.

---

## 🌟 Funcionalidades
* **Processamento Batch**: Permite converter várias imagens rapidamente de forma automática;
* **Redimensionamento**: Permite redimensionar imagens, mantendo sua proporção original;
* **Compressão**: Permite reduzir o tamanho de arquivos de imagem;
* **Conversão**: Permite converter para os formatos .jpeg, .webp ou .avif.
